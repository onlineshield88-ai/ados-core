# ADOS

**AI Development Operating System**

> Build software like a software house. Continue development with any AI model without losing project context.

---

## What is ADOS?

ADOS (AI Development Operating System) is an engineering framework designed to organize software development for both humans and AI agents.

Instead of relying on chat history, ADOS stores project knowledge inside the repository through documentation, specifications, standards, and workflows.

The repository becomes the single source of truth.

---

## Vision

Create an AI-native software engineering ecosystem where any AI can continue development simply by reading the repository.

Supported AI models include:

* ChatGPT
* Claude Code
* OpenAI Codex
* Cursor
* Aider
* OpenHands
* Future AI models
