# ROADMAP

Project: ADOS (AI Development Operating System)

Current Version: 0.1.0

Current Stage: Foundation

Status: Active Development

---

# Product Vision

ADOS is an AI-native software engineering operating system.

Its purpose is to enable any AI model to continue software development from repository knowledge instead of chat history.
